학술행사에서 맡는 일

등록 / 참석자

사전등록과 현장등록, 명찰, 자료 배포, 세션 안내와 참석자 이동을 담당합니다.

좌장 / 연자 관리

좌장과 연자의 도착, 대기 위치, 무대 입장, 발표 순서와 시간을 현장에서 관리합니다.

세션 / 발표자료

세션별 큐시트, 발표자료 취합, 파일 백업, 영상과 PPT 전환, 질의응답을 담당합니다.

송출 / 촬영

온라인 중계, 강연 녹화, 현장 사진과 세션별 영상 촬영을 진행합니다.

학회 / 심포지엄 문의가 많은 내용

학회 발표자료를 사전에 취합할 수 있나요?

네. 발표자료 제출 일정 관리, 최종본 확인, 현장 백업과 화면 전환을 맡을 수 있습니다.

여러 개 세션룸을 동시에 운영할 수 있나요?

네. 세션룸별로 운영 인력, 발표자료와 장비를 배치해 동시에 운영할 수 있습니다.

학술행사를 온라인으로도 송출할 수 있나요?

네. YouTube와 Zoom 실시간 송출, 세션별 녹화를 진행할 수 있습니다.

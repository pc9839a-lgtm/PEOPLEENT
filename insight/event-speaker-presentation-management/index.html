행사 연사·발표자료 제출 관리 체크리스트

행사 당일의 가장 흔한 혼선은 ‘발표자료를 받았다’는 사실과 ‘무대에서 재생 가능한 최종본을 확보했다’는 사실을 혼동할 때 생깁니다. 연사 명단부터 파일 버전·룸 배정·기술 리허설까지 분리해 관리하는 방법입니다.

연사 정보 기준표자료 제출·버전 관리리허설변경 승인
이 글의 활용 범위

행사 운영 실무를 위한 참고 자료입니다. 계약이나 행사장별 조건, 주최 측 승인, 개인정보·저작권 관련 요구사항을 대신하지 않습니다. 제공된 양식은 복사해 사용할 수 있으며 자동 저장·서버 전송되지 않습니다.

1. 연사 담당과 무대 기술 담당의 책임을 분리

연사를 섭외한 조직, 학술 내용과 발표 제목을 승인하는 조직, 현장에서 발표 파일을 여는 담당자는 같지 않을 수 있습니다. 특히 학회·컨퍼런스에서는 주최 학회·사무국·PCO·행사 운영팀 간 승인 업무를 혼동하지 않도록 정리해야 합니다.

업무정보를 확정하는 주체(예시)현장으로 전달할 자료
발표 주제·섭외주최 측 프로그램·학술 담당초청·확정 명단, 세션 배정
연사 이름·소속·직함연사 본인 확인 + 주최 측 승인정확한 표기·발음·소개문 기준본
발표자료 접수연사 연락 담당·사무국접수 상태·파일 위치·마감 시점
파일 기술 검수영상·PPT 오퍼레이터·음향 담당실제 재생 결과·대체 파일·질문 목록
무대 등단·Q&A세션 진행자·좌장·무대 PM무대 동선·시간 신호·발표 순서
수정·배포 승인주최 측 지정 승인자·저작권자최종 파일·촬영·공개 가능 범위

발표 내용과 저자·기관 표기의 학술적 적정성은 운영팀이 임의로 판단하지 않습니다. 연사 섭외나 학술 심사가 운영사 계약 범위에 포함돼 있는지도 별도로 확인해야 합니다.

2. 연사 정보는 하나의 기준표로 관리

연자별 정보가 메신저·메일·프로그램북·현장 PPT 폴더에 흩어져 있으면 수정이 발생할 때 서로 다른 버전이 남습니다. 변경 승인을 받는 하나의 기준표를 정하고, 인쇄물·안내 화면·사회자 소개·촬영 파일 이름에 동일한 표기를 적용합니다.

필수 항목예시 값·확인 방식확정 담당
연사·소속 표기성명, 발표자 요청 표기, 직위·기관명, 영문 표기주최 측 및 연사 확인
발표 슬롯행사 날짜·룸·세션·시작·종료 시간프로그램 승인자
발표 환경본인 노트북/현장 PC, 발표 화면 비율, 유선 클릭커, 영상·음향 포함 여부현장 기술 담당
자료 접수제출 마감·파일명·접수 채널·검수 상태연사 연락 담당
이동·대기도착 시각·대기 공간·무대 이동, 원격 접속 시각연자 응대 담당
촬영·자료 공개녹화·송출·자료집·다시보기 허용 여부주최 측·연사 승인
공개용 프로그램과 내부 연사 관리표는 다릅니다

출입 연락처·대기실·비공개 메모 등 내부 운영 정보가 참가자 배포용 프로그램에 포함되지 않게 구분하세요. 개인 연락처·출입 관련 정보의 취급 범위는 주최 측 정책과 적용되는 개인정보 규정에 따릅니다.

3. PPT·PDF·동영상 제출 마감과 최종본을 구분

‘PPT 제출 완료’는 파일이 도착했다는 뜻일 뿐 화면 출력과 음성 재생까지 정상이라는 뜻은 아닙니다. 제출 단계·기술 검수·최종 확정·현장 변경을 각각 별도 상태로 관리합니다. 발표자가 행사장 PC 대신 개인 노트북을 쓰는 경우도 입출력과 파일 공유 대체안을 확인하세요.

접수 상태의미다음 단계
미제출요청한 자료를 수신하지 못함연사 연락 담당이 마감·제출 경로 확인
접수 완료파일은 받았으나 기술 검수 전룸·연사·파일 버전 식별 후 화면 테스트
기술 확인 중글꼴·영상·음향·비율·연결 점검 필요실제 행사 장비로 리허설
검수 완료현재 파일 버전에서 기술 시험 통과주최 측 내용 승인·최종 제출 시각 확인
최종 확정진행표와 룸별 발표 파일이 같은 버전현장 변경 승인 절차로 관리
현장 교체기존 최종본 이후 새 파일 접수변경 승인·교체 사유·버전·시간 기록

파일명·폴더 구조 예시

‘최종’이라는 이름만으로 버전을 판정하지 않습니다. 행사장 운영자가 사용하는 기준표와 교체 승인 기록이 일치해야 합니다.

폰트가 없는 장비에서 글자가 달라지거나, 발표 영상이 외부 파일로 연결돼 재생되지 않거나, PPT 애니메이션·맥/윈도우 호환 문제로 화면이 깨질 수 있습니다. 현장 장비에서 파일을 직접 여는 시험을 권장합니다.

4. 화면 전환·음향·원격 연결을 실제 순서로 리허설

연사가 발표 내용을 처음부터 끝까지 읽는 것보다 무대 입장, 첫 슬라이드 전환, 동영상 소리, Q&A 마이크, 다음 연사로 넘어가는 전환 지점을 우선 확인하는 편이 기술적 누락을 찾는 데 유용합니다. 기술 점검 결과는 담당자·시각과 함께 남기세요.

검수 구간실제 확인오류 발견 시
발표 시작연사명과 세션·룸 일치, 첫 장 정상 출력기준표·파일명 대조
화면 비율LED·스크린·발표 PC 출력 비율, 화면 잘림장비 설정·다른 출력 파일 확인
글꼴·영상폰트 대체·오브젝트 변형·영상 삽입·코덱 재생PDF 대체 가능 여부·영상 별도 재생 준비
음향발표 영상 소리·마이크·원격 연사 오디오 경로현장·송출 채널별 테스트
리모컨·클릭커슬라이드 이동·강연 종료 신호오퍼레이터 수동 전환 대체안
원격 연사타임존·접속 링크·화면 공유·반환 음향·재접속연사 연락 담당·백업 자료 사용 승인

두 개 이상의 세션룸이 동시에 운영된다면 각 룸에서 독립적으로 테스트하고, 한 사람이 여러 룸의 발표자료를 동시에 전환하도록 배치하지 않습니다. 현장 인력 업무 분장과 연결해 확인하세요.

5. 연사 불참·당일 파일 교체·발표 지연 대응

프로그램과 발표자료의 최종본이 확정된 뒤에도 변경이 발생할 수 있습니다. 중요한 것은 파일 교체 자체보다 누가 승인하고 그 승인 사실이 어느 담당자에게 전달되는지입니다. 다음은 행사 운영에 활용할 수 있는 가상의 상황입니다.

문제 상황즉시 확인전파해야 할 담당
연사 불참·지연대체 발표자·발표 순서·공식 공지 승인주최 측, 좌장·무대 PM, 등록·안내, 기술·촬영
발표 주제·소속 수정공식 소개·프로그램·PPT 표기 최종 승인사회자, 현장 스크린, 프로그램 제작 담당
파일 교체 요청새 버전 전달·대체 파일 필요성·기술 리허설 가능 시간룸별 PPT 오퍼레이터, 음향·송출·촬영
원격 연사 연결 중단재접속 시간·화면 공유·대체 순서·녹화 사용 권한세션 좌장, 주최 측 승인자, 온라인 진행
세션 지연·시간 초과남은 발표·휴식·다음 룸 동선에 미치는 영향좌장, 세션 PM, 안내·등록 인력
가상 상황: 행사 직전 연사가 새 PPT를 전달했다면

연사 담당자는 새 파일 접수 시각과 버전을 기록하고, 주최 측이 내용 변경을 승인했는지 확인합니다. 그다음 해당 세션룸 기술 담당자는 실제 행사 장비에서 첫 장·영상·음향 등을 다시 테스트합니다. 교체가 승인되면 기존 파일을 즉시 삭제하기보다 승인된 백업 정책에 따라 보관해 장애 시 복구 가능성을 확보합니다. 실제 수행 사례나 일률적인 업무 보장은 아닙니다.

6. 연사에게 보내는 발표자료 요청·변경 인계 양식

아래 요청문과 관리 항목은 직접 수정해 복사할 수 있습니다. 행사명·연사명·자료 제출 마감·기술 요구사항·연락처·촬영 승인 범위는 실제 조건으로 채운 후 보내세요.

수정 가능한 실무 양식

확정되지 않은 항목은 확인 필요로 표시하고 발송 또는 현장 사용 전에 담당자에게 최종 검수를 받으세요.

자주 묻는 질문

연사가 PPT 파일을 보냈다면 현장 운영 준비가 끝난 건가요?

아닙니다. 파일 접수와 실제 행사 장비에서의 기술 검수, 프로그램·룸·연사명 일치, 주최 측 내용 승인, 최종본 확정은 별도 단계입니다.

행사 당일에도 발표자료 교체가 가능한가요?

가능 여부는 행사 운영 조건과 남은 리허설 시간에 따라 달라집니다. 주최 측 승인, 파일 식별, 화면·음향 재시험, 해당 룸 오퍼레이터에게 최종 버전 전파가 필요합니다.

연사 발표자료와 강연 영상을 참가자에게 배포해도 되나요?

현장 발표를 위해 받은 파일과 외부 배포·녹화 활용 권한은 별개입니다. 저작권·비공개 정보와 연사·주최 측이 허용한 공개 범위를 확인해야 합니다.

해외 원격 연사가 접속하지 못하면 어떻게 하나요?

재접속 지원과 연락망, 발표 순서 조정 및 백업 자료 사용 가능 여부를 사전에 정해야 합니다. 세션 변경·대체 발표 여부는 주최 측과 좌장 등 승인 담당자가 결정합니다.

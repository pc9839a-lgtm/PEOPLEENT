행사 큐시트 작성법과 현장 진행 요령

큐시트는 프로그램 순서를 보기 좋게 적은 문서가 아닙니다. 사회자, 무대 감독, 음향, 영상, 조명, 진행 요원이 같은 순간에 무엇을 해야 하는지 맞추는 실행표입니다. 당일 진행이 꼬이지 않으려면 장면마다 책임자와 확인 신호가 있어야 합니다.

행사 순서표와 큐시트는 다릅니다

행사 순서표에는 ‘14:00 개회, 14:05 환영사, 14:15 발표’ 정도면 충분할 수 있습니다. 하지만 실제 현장 큐시트에는 사회자 멘트 종료 신호, 배경 음악 감쇠, 화면 전환, 발표자 입장 위치, 핸드 마이크 전달 담당까지 적어야 합니다.

중요한 것은 초 단위 정밀함 자체가 아니라 누가 결정하고 누가 실행하는지입니다. 큐 변경 지시를 여러 사람이 동시에 내리면 장비팀은 서로 다른 지시를 받게 됩니다. 현장 총괄 또는 무대 감독의 승인 경로를 한 가지로 정합니다.

실무 확인 항목

  • 행사 순서표와 기술 큐시트 분리
  • 최종 승인자 표기
  • 스태프 연락 채널 통일

한 줄에 필요한 최소 열

‘시각 / 구간 / 진행 내용 / 사회자·발표자 / 음향 / 영상 / 조명 / 무대·동선 / 담당자 / 비고’ 열을 권합니다. 예를 들어 환영사가 시작될 때는 영상팀이 타이틀 화면을 종료하고, 음향팀이 무선 마이크를 열고, 현장팀이 다음 발표자를 대기실에서 이동시킵니다.

같은 시간에 두 가지 행동이 겹치는 경우가 흔합니다. 이때는 한 셀에 모든 지시를 적지 말고 ‘발표자 입장’과 ‘오프닝 영상 종료’를 다른 행으로 나누면 현장에서 빠르게 확인하기 좋습니다.

실무 확인 항목

  • 문서 버전과 최종 수정 시각
  • 파일명·영상 재생 위치
  • 인계 담당과 입장 지점

특히 사고가 잦은 전환 구간

오프닝 영상 종료 후 사회자 등장, 시상식에서 수상자 호명 후 무대 이동, 패널토론에서 마이크 전달, 발표 직후 Q&A 전환이 자주 혼잡해지는 구간입니다. 영상 종료 화면을 누가 확인하는지, 사회자 대기 사인을 누가 주는지 미리 합의해 둡니다.

케이블 교체나 프로젝터 입력 전환이 필요한 경우에는 해당 구간에 완충 시간을 둡니다. 장비 작동을 앞당길 수 없다면 사회자 브리지 멘트나 대체 이미지로 어색한 공백을 줄일 수 있습니다.

실무 확인 항목

  • 영상 종료 후 전환 사인
  • 무대 진입·퇴장 동선
  • 마이크 전달 담당
  • 완충 멘트 확보

리허설은 발표 전체보다 전환점을 우선 점검합니다

발표자가 모든 내용을 읽어보는 것보다 화면 전환, 등장·퇴장, 마이크 전달, 시상 기념 촬영과 같은 장면을 반복 점검하는 편이 제한된 리허설 시간을 잘 쓸 수 있습니다.

실제 장비에서 영상 파일을 열어보고 화면비와 자막 잘림을 확인하십시오. 발표 자료 최종본, 로컬 백업, 영상 원본, 폰트 호환성을 같은 담당자가 점검하도록 합니다. 온라인 송출이 있다면 현장 소리와 온라인 소리도 각각 확인해야 합니다.

실무 확인 항목

  • 기술 리허설
  • 실제 파일 재생
  • 예비 노트북·케이블
  • 송출 모니터링

행사 지연·연사 불참에 대비합니다

지연이 발생했을 때 어떤 순서를 줄일지 우선순위를 정해 두면 좋습니다. 안내 멘트, 휴식 시간 축소 여부, 질의응답 종료 기준을 즉흥적으로 결정하지 않도록 협의합니다.

연사가 늦으면 다음 세션을 당겨도 되는지, 원고 없이 사회자가 대신 안내할지, 화면에는 무엇을 노출할지까지 가급적 정합니다. 연락망과 승인권자를 큐시트 마지막에 적되 개인 연락처가 외부에 공개되지 않도록 배포본을 분리합니다.

실무 확인 항목

  • 지연 시 축약 가능한 구간
  • 연사 변경 대체 순서
  • 돌발 중단 의사결정자

최종본 운영 규칙을 하나로 정합니다

큐시트가 여러 파일로 떠돌면 최신본이 무엇인지 확인하는 시간이 늘어납니다. 파일명에 일자·버전을 넣고 현장 공유 위치를 통일합니다. 출력본에는 버전을 인쇄하고 당일 변경은 총괄이 구두 확인 후 반영합니다.

운영 종료 뒤에는 변경된 실제 시간을 기록하면 다음 행사의 기준자료가 됩니다. 제작물과 발표자료의 최종 승인 여부를 다른 문서로 관리하더라도 큐시트에서는 승인된 버전을 참조하도록 연결해야 합니다.

실무 확인 항목

  • 배포본 버전 통제
  • 변경 이력
  • 행사 종료 후 운영 회고

자주 묻는 질문

Q. 큐시트는 행사 며칠 전에 확정해야 하나요?
행사 특성에 따라 다릅니다. 최소한 기술 리허설 전에는 장면·담당자·파일명이 확정되어야 하고, 당일 변경 절차를 정해 두는 것이 중요합니다.
Q. 간단한 세미나도 큐시트가 필요하나요?
영상 재생이나 발표자 교대가 있다면 간략형이라도 유용합니다. 대형행사처럼 복잡하게 만들 필요는 없습니다.

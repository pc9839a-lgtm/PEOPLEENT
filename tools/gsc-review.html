Google 색인 상태를
URL별로 대조하기

Search Console에서 직접 내보낸 자료와 사이트맵의 공개 URL 35개를 비교합니다. 제외 사유와 검색 성과를 구분하고 우선 확인할 페이지를 정리할 수 있습니다.

개인 브라우저에서만 분석: CSV 파일·검색 데이터는 서버로 업로드하거나 저장하지 않습니다. 이 페이지의 방문 분석도 비활성화되어 있습니다. 업로드하지 않은 URL의 색인 상태는 미확인으로 표시합니다.
01. Google Search Console에서 내보내기

페이지 색인 사유별 예시 URL 목록을 CSV로 준비합니다.

02. 상태별 CSV를 추가

상태를 고르고 파일을 가져옵니다. 파일별로 반복할 수 있습니다.

03. 검색 성과와 대조·내보내기

선택적으로 검색 실적의 '페이지' CSV를 가져와 결과표를 저장합니다.

1. 색인 상태별 URL 목록

Search Console '페이지 색인'에서 개별 사유를 열어 예시 URL 목록을 내보낸 CSV를 사용합니다. 전체 원인·페이지 수 집계표는 URL별 분류에 사용할 수 없습니다.

같은 URL이 다른 상태 파일에 있으면 임의로 덮어쓰지 않고 '상태 충돌'로 표시합니다.

2. 검색 실적 (선택)

Search Console '검색 실적 → 페이지'의 클릭·노출 CSV를 가져옵니다. 검색 실적에 없는 URL을 미색인으로 판정하지 않습니다.

두 번째 파일을 가져오면 이전 검색 실적은 대체됩니다. 중복·기간 겹침으로 합계가 부풀지 않도록 합니다.

검색 클릭·노출의 '—'은 해당 자료가 없다는 뜻입니다. 0이나 미색인 상태를 의미하지 않습니다. 파일 업로드 없이 보이는 기본 목록은 모두 색인 상태 미확인입니다.

어떤 CSV를 가져와야 하나요?

Search Console의 페이지 색인 보고서에서 특정 제외 사유를 선택하고, 하단의 예시 URL 목록을 CSV로 내보낼 수 있다면 해당 파일을 가져오세요. 내보내기 메뉴와 열 이름은 계정·언어에 따라 다를 수 있습니다.

  • 예시 URL이 없는 '이유별 총 페이지 수' 파일은 개별 페이지의 색인 상태를 알려주지 않습니다.
  • 검색 실적 CSV는 페이지별 클릭·노출을 알 수 있지만, 노출이 없는 페이지를 자동으로 색인 제외로 분류하면 안 됩니다.
  • 예시 URL은 Search Console 화면의 전체 URL을 모두 포함하지 않을 수 있습니다. 누락된 URL은 '미확인'입니다.
  • 상태 충돌은 수집 날짜 또는 Google 선택 canonical이 다른 경우일 수 있으므로 최신 URL 검사 결과로 다시 확인하세요.
PEOPLEENT · URL 분석 결과는 사용자 브라우저에서만 처리됩니다. Google의 실제 색인 여부는 Search Console 원본 자료에서 확인해야 합니다.
